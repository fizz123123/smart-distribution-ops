# 營運分析與儀表板需求

> 需求版本：v1.0  
> 建立日期：2026-09-29  
> 文件定位：定義本次專題交付範圍內的儀表板問題、指標口徑、分析規則、下鑽與驗收方式。

## 分析目的

儀表板的目的不是堆疊圖表，而是協助管理者針對以下問題採取行動：

1. 本期接單或已過帳銷售為何上升或下降？
2. 哪些訂單與商品有缺貨或延遲風險？
3. 哪些客戶的交易行為正在降溫？
4. 有多少應收尚未收回、即將到期或已逾期？
5. 哪些核准、採購、入出庫或財務事項需要優先處理？

每項指標須有固定口徑、資料期間、權限範圍及來源連結。

## 期間與金額口徑

- 儀表板預設期間為目前自然月。
- 本期為使用者選擇的日期區間。
- 前期為緊接本期之前、長度相同的日期區間。
- 近六個月趨勢固定以自然月分組。
- 接單、銷售與客戶貢獻一律採未稅 TWD。
- 含稅金額只用於應收與收款，不與未稅營運指標混合彙總。

## 營運總覽

首頁至少呈現：

- 本期新增核准 SO 數。
- 本期新增核准接單額。
- 本期核准取消額與淨接單變動。
- 本期已過帳銷售金額。
- 本期平均新增訂單金額。
- 本期活躍客戶數與下單客戶數。
- 目前缺貨風險品項數。
- 以今日為基準的交易降溫客戶數。
- 應收總額、未收餘額、即將到期及逾期金額。
- 待財務確認的應收草稿。
- 目前待核准及待處理事項數。

期間型指標會隨日期篩選改變；缺貨風險、未收、到期、逾期及待辦事項是目前時間點的快照，不受一般期間篩選影響。交易降溫依所選分析基準日計算，首頁預設為今日。

## 接單與銷售指標

```text
本期新增核准 SO 數
＝本期首次核准的 SO 張數

本期新增核准接單額
＝本期首次核准 SO 的未稅原始金額

平均新增訂單金額
＝本期新增核准接單額÷本期新增核准 SO 數

淨接單變動
＝本期新增核准接單額－本期核准取消額

本期已過帳銷售金額
＝本期 DO 實際出貨數量×SO 未稅價格快照
```

- 核准取消額依取消實際核准期間計算，不回溯改寫原 SO 核准月份。
- 平均新增訂單金額不以淨接單變動計算。
- 活躍客戶為本期至少有一張 DO 過帳的客戶。
- 下單客戶為本期至少有一張 SO 首次核准的客戶。
- 已接單未出貨金額是即時存量，以有效訂購數量扣除已出貨及已核准取消數量計算。
- 本次專題未串接會計總帳，因此已過帳銷售金額不稱為會計營收。

## 銷售變化分析

至少提供：

- 近六個月新增核准接單額、取消額、淨接單變動與已過帳銷售趨勢。
- 本期與前期的訂單數、平均訂單金額及活躍客戶數比較。
- 依客戶與商品拆解的銷售增減貢獻排行。
- 已接單未出貨金額與原因，用來區分需求下降及出貨遞延。

管理者可由結果決定是否聯繫交易下降的主要客戶、處理缺料、檢視商品需求或調整經營優先順序。

## 應收分析

- 應收總額只包含 `OPEN`、`PARTIALLY_PAID` 與 `PAID` 的正式含稅應收，不包含 `PENDING_CONFIRMATION` 或已作廢資料。
- 未收餘額為正式應收含稅金額扣除已核銷收款。
- `PENDING_CONFIRMATION` 另以待確認筆數及含稅金額呈現。
- 即將到期為未收餘額大於 0 且 `今日≤到期日≤今日＋7 天`。
- 逾期為未收餘額大於 0 且到期日早於今日。

## 缺貨風險分析

本次專題使用可說明依據的規則，不使用機器學習預測。清單至少整合：

- 商品。
- `AVAILABLE`、`RESERVED`、`QUARANTINED`、`DAMAGED`。
- SO 未預留需求及尚待規劃供應量。
- PO 已規劃供應量與正式採購在途量。
- PO 預計到貨日與客戶要求交貨日。

符合下列任一條件時可標示風險：

- `AVAILABLE` 低於安全庫存。
- 已核准 SO 仍有尚待規劃供應量。
- SO 缺料只有 PO 草稿或待核准 PO，尚未形成正式採購在途。
- 已核准 PO 的預計到貨日晚於客戶要求交期。
- 已超過預計到貨日但尚未完成合格入庫。

管理者可由清單建立或催辦 PO、催促供應商、協調交期或評估分批出貨。只有安全庫存不足、沒有 SO 缺料時，可建立一般補庫 PO 草稿。本次專題不自動決定採購量、不自動送審或下單。

風險與供應狀態至少區分：

- 缺料待處理。
- 已規劃、未下單。
- 採購在途。
- 部分到貨。
- 採購延遲風險。
- 已備齊。

## 客戶交易降溫分析

工程材料 B2B 客戶常依工程進度不定期採購，因此本次專題只稱為「交易降溫風險」，不直接判定客戶流失。至少比較：

- 最後交易日期與距今天數。
- 歷史平均交易週期。
- 近期與前期的已核准 SO 數量及金額。
- 近期與前期的已過帳 DO 金額。
- 近期缺料、延遲出貨與取消紀錄。

系統可依距上次交易時間是否明顯超過個別客戶平均週期，或近期訂單數及金額是否明顯下降，標示低、中、高風險。結果供業務確認及安排聯繫，不由系統自動判斷客戶關係或採取對外行動。

## 下鑽與權限

- 指標與警訊須能連回形成結果的客戶、商品、SO、PO、DO 或應收紀錄。
- MANAGER 可查看全公司結果。
- 採購與倉管依職務查看缺貨、補貨及履約資訊，但不因此取得非必要價格或成本。
- 業務主管查看部門範圍；一般業務查看自己負責的 SO。
- 所有明細仍受 [04-roles-and-permissions.md](04-roles-and-permissions.md) 約束。

## 分析驗收原則

- 相同期間與條件下，指標卡、圖表、下鑽明細及 AI 摘要使用一致結果。
- 管理者可從警訊回到來源紀錄驗證原因。
- 使用者只能取得其權限範圍內的統計與明細。
- 資料不足時明確顯示，不以 AI 補造結論。
- 展示資料使用匿名化匯入資料或合理模擬資料，讓趨勢、風險與結果可被重現。

風險門檻與展示資料範圍尚未定案，見 [09-decision-log.md](09-decision-log.md)。
